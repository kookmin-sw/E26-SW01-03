## 3️⃣ 한학기 동안의 활동 내역 

- 기관/부서 인터뷰 ✔️  

- 현장 탐방 ✔️  

- 멘토링 ✔️  
  - 내 지도 교수 함게 만나기
  - 대학원 방문 및 선배 만나기

- 프로젝트 진행 ✔️  
  - 과거에 사람들이 상상한 미래
    - Team Mission 1 🔎 과거 사례 4분류 및 근거 작성

     ✔️ 현재 가능
         1. 태양열 발전 주택 : 주택에 태양광 발전 설비 설치 가능
         2. 로봇 청소기 : 실제 가정에서 사용 가능
         3. 원격 학습 : 온라인 강의나 화상수업이 일상적임

     🔘 일부 가능
         1. 전기, 자율주행차 : 전기 자동차는 상용화, 자율주행 자동차는 발전 중
         2. 움직이는 도로 : 무빙워크는 존재, 실제 도로가 움직이는 형태는 아님
         3. 원격 진료 : 기술적으로 가능하지만 아직 제한적
         4. 스마트 부엌 : 스마트 가전은 있지만 그림과 같은 형태는 아님

     ⏳ 아직 어려움
         1. 달나라 수학여행 : 일반인이 편히 달나라로 여행을 갈 수 없음

     🔀 방향 전환
         1. 소형 TV 전화기 : 더 발전된 스마트폰이 상용화되어 있음
         2. 전파 신문 : 인터넷, 스마트폰으로 뉴스 실시간 전달 가능
  
    -Team Mission 2  🔎 Why-What-How 심층 분석 [소형 TV 전화기]

     ❓ Why : 과거에는 대부분의 소통과 업무가 대면 중심으로 이루어져 시간과 장소의 물리적 제약이 존재
     💡 What : 시간과 장소의 제약을 넘어 언제 어디서나 소통하고 정보를 이용할 수 있는 환경을 구현
     ⚒️ How : 기기의 경량화, 유선에서 무선으로 변화, 인터넷 인프라의 발전, 
              스마트폰이라는 기기의 등장으로 다양한 생활 편의를 제공하는 종합적 도구로 성장
     ➡️ Next : 스마트폰 중독, 개인정보 문제, 디지털 격차, 온라인에서의 윤리적 문제가 자리잡음
              물리적 크기의 한계, 이동통신의 한계(완벽한 연결 보장 X), 베터리 발열 문제
    
  - 그들이 만들어가는 세상
  - 우리가 상상한 미래
  - 우리가 그리는 미래 그리고 나

- 각오와 소감 나누기 ✔️
